# BQ79616 断线诊断分析：定量模型与"哨兵+复核"判别法

> 2026-09-05，Wonder 提出，Simon 整理；同日经应用工程师（Wonder）定量解答后修订。
> 场景：断线是采样回路阻抗由小变大的渐变过程，OV/UV（实时硬件 protector）总是先动作，断线往往报不出来。

## ⚠️ 结论修正记录（2026-09-05）

初版本文曾认为"调高 OW_TH + 缩短轮询可以让断线先于 OV/UV 报出"——**该结论不成立**：
- OW_TH 取值上限受"必须低于最低正常电芯电压（防健康通道误报）"约束，实际只能取低档
- 诊断电流（典型 500µA）本身就会把带阻通道的采样电压拉穿 UV 门限——诊断动作自己会触发 UV
- 因此"渐变断线先报欠压"是**物理次序，不是配置问题**。正确目标是：**UV 触发后准确甄别断线与真欠压**（见下方判别法）

## 定量模型（一阶）

采样点电压：`V_pin = V_cell − I_diag × R_wire`

两类故障的触发边界电阻：`R_边界 = (V_cell − V_TH) / I_diag`

- 616：I_diag = **IOW_SINK 500µA typ（380–600µA，公开版手册电气特性表）**
- 算例（V_cell=3.3V，OW_TH=0.5V）：R_OW 边界 = (3.3−0.5)/500µ = **5.6kΩ**；线阻 >5.6k 才判断线
- 若 UV_TH≈2.8V：R_UV 边界 = (3.3−2.8)/500µ = **1kΩ** —— 渐变过程中 1k 就报 UV，远早于 5.6k 的 OW，且诊断期间 protector 一直在看
- 718 同思路但诊断电流为 µA 级（低约两个数量级），断线判定边界相应外推至百 kΩ 量级；小电阻渐变更不会报断线（具体值见所用版本 datasheet 电气特性表 ILEAK_VC_CB，含 NDA 数据不入本卡）

## 均衡判别法（应用工程师实战方案）：UV 触发后的甄别与定位

**思路**：欠压（UV）是天然的快速哨兵——接受它先报；UV 触发后用均衡电流做**激励**，读 VC 响应反推回路状态。

**判据**（对报 UV 的通道开一次均衡，然后读该通道 VC）：
- VC 电压**跌至 ≈0** → 采样线断线/高阻（均衡电流经线阻把节点拉死）
- VC 电压**跌落 <500mV** → 真欠压（健康线阻仅 mΩ~几十Ω，跌落微小）

**操作细节（系统级自洽）**：
1. 均衡时**相邻通道**读数会升至 ~1.5× 电芯电压 → 判别期间必须**屏蔽 OV**，否则自己制造误报
2. 单通道报 UV → 只开该通道即可；多通道报 UV → 按**奇偶分两批**（相邻通道不能同时开均衡）
3. 判别完成后清除均衡状态与本次屏蔽的 OV 记录

**为什么这方法好**：零 BOM 成本（复用片上均衡 FET）；逐通道定位；把"报障次序"问题转化为"触发后甄别"问题，绕开了物理上不可行的"抢报"。

## 补充手段：VBAT vs ΣVCELL 交叉校验

- 断线通道使 ΣVCELL 偏离 VBAT（差值 ≈ 失联通道电压），可区分真低压与断线
- 粒度粗于均衡判别法，适合做系统级兜底校验（来源 SDAA369）

## 原理：为什么 OV/UV 先报

断线后电流沉泄放 Cvc 滤波电容：本通道读数缓降 → 触发 CUV；上方邻通道读数等比上升 → 触发 COV。OV/UV 是持续运行的硬件 protector，OW 是 host 主动轮询的诊断；且诊断电流本身会拉低采样电压，渐变过程中 protector 必然先触发。（SDAA369 以 BQ76952 为例说明同一机理。）

## 机理：为什么 OV/UV 先报

断线后电流源/沉泄放 Cvc 滤波电容：

- 本通道读数缓降 → 触发 **CUV**
- 上方邻通道读数等比上升 → 触发 **COV**

OV/UV 是持续运行的硬件比较器；OW 是 host 主动轮询的诊断。渐变过程中 protector 必然先触发。
（SDAA369 以 BQ76952 为例说明同一机理；BQ769x2 甚至没有专用 OW 位。）

## 616 的三条解法（可叠加）

### ① 调高 OW_THR（核心）

渐变断线 = 回路阻抗 R 增大。OW 检查时电流沉 I_sink 叠加，读数分压比正常测量更狠：

- 正常测量跌破 UV 阈值需要较大的 R
- OW 检查跌破 OW_THR 需要的 R 小得多 → **同一渐变过程中 OW 判据先满足**

OW_THR 取值：保证 < 最低正常 cell 电压（防误报）的前提下尽量高，灵敏度最高。

### ② 缩短 OW 轮询周期

诊断可随时反复执行（E2E 确认 BIST/诊断不限启动时刻）：

```
DIAG_COMP_CTRL3[OW_SNK1:0]=01 开 VC 电流沉
→ 等 dV/dt（I_sink 对 Cvc 放电到阈值）
→ COMP_ADC_SEL=010，COMP_ADC_GO=1
→ 等 DRDY_VCOW → 读 FAULT_COMP_VCOW1/2 → 关电流沉
```

塞进主循环周期执行，断线后一轮内报 OW。注意：检查期间电流沉会扰动读数，避开均衡/保护判定窗口。

### ③ host 端仲裁 + VBAT/ΣVCELL 交叉校验

- OV/UV 触发时 host 先跑一轮 OW 检查再上报，是 OW 就归类为断线
- **VBAT vs ΣVCELL 比对**（SDAA369 方法）：断线通道使 ΣVCELL 偏离 VBAT，差值 ≈ 失联通道电压 → 区分真低压与断线
