# EIS激励模块 知识卡片

> 知识卡片 = 结论与指针；原始文件在 Zotero，本地缓存不入 git。

## 是什么

TI 的 **EIS 激励板 EISEXCEVM-104（BMS104）**：给内置 Smart EIS Engine 的车规 BMS AFE（BQ79826Z-Q1）做电化学阻抗谱测量时的**外部激励电流发生器**。作为配件板（add-on EVM）接在 BQ79826QEVM-086 上，两板组合即可对单芯到多串电芯包做即插即用的 EIS 评估，不限电芯化学体系。附件含用户指南（SLUUDC0，2025-07，TI Selective Disclosure 级别）与该板原理图（EIS Lin Exciter，Rev E0）。**具体规格数值属受限披露，不记入本卡，见 Zotero 条目。**

## 关键内容

### 系统架构（两板方案）

- AFE 侧：BQ79826-Q1 的片上 EIS 引擎负责**测量与激励波形生成（PWM）**；PC 经 USB2ANY + SPI 走 GUI 控制
- 激励板侧：产生**线性（linear）激励电流**注入电池。AFE 与激励板之间**仅用一根 DSUB-9 线缆**互连，全部信号（PWM、EIS 使能、SRP/SRN 电流检测回线、NTC 测温、供电）都走这一根线；电池同时接到两板（AFE 测 cell 电压，激励板走大电流回路）

### 激励板三条电路链路（原理图 3 页：PWM Filter / Exciter / Hardware）

1. **PWM 滤波**：运放把 AFE 送来的 PWM 整形成干净的正弦激励波形（Vexc），并叠加直流偏置保证运放工作在线性区
2. **线性激励级**：线性功率 MOSFET + 多颗铝壳大功率限流电阻（装散热器、涂导热硅脂）；通过**跳线选择限流电阻组合**来配置激励电流幅度、匹配不同电池电压范围；毫欧级采样电阻经开尔文（Net-Tie SRP/SRN）接运放检测激励电流，回传 AFE 闭环
3. **辅助与监测**：高压输入 buck 专为**板载风扇**供电（散热）；板载 NTC 测温；EIS_EN 信号经电源开关控制本板上电

### 主要芯片（定性清单，原理图）

- 运放：TLV9102（双通道）+ TLV9161-Q1（车规单通道），用于滤波、偏置与电流检测反馈（高精度电阻抑制直流偏置误差）
- 功率级：IRFP244 MOSFET（贴散热器）+ 大功率限流电阻串
- 电源：UCC28881（高压输入 buck，风扇供电）、TPS22810-Q1（EIS_EN 使能的电源开关）
- 其他：ERT-J 系列 NTC、TPD1E05U06-Q1（ESD 保护）、DSUB-9 与大电流电池连接器

## 应用要点

- 定位是**评估板而非产品方案**：EIS 引擎在 AFE 片上，但激励电流靠外置板产生——这就是"Smart EIS"方案的系统级拆分，客户问"EIS 还要外加东西吗"时的标准答案
- 激励电流可达**安培级**、工作电压覆盖高压模组（具体数值见 Zotero）；激励幅度通过换电阻/跳线配置，不是纯软件连续可调
- **安全警示（原理图多处强调）**：大电流路径无保险丝；跳线配置错误可能损坏 MOSFET；**上电前必须先用万用表确认总阻值**、核对电池电压范围与跳线表
- **热设计是主要难点**：线性激励级效率低，风扇 + 散热器 + NTC 监测是必需配置；产品化时的核心参考点
- 与卡片《BQ79826》互参：该 AFE 的 EIS 规格（阻抗精度、频段）在 AFE 卡片中，激励实现细节在本卡片
