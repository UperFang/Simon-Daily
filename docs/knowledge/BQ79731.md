# BQ79731 知识卡片

> 知识卡片 = 结论与指针；原始文件在 Zotero，本地缓存不入 git。

## 是什么

TI 车规 **BJB（电池接线盒）/UMI 传感器**：高压节点测量 + 电流检测 + 绝缘检测，AEC-Q100 -40~125°C，ASIL D。用于电池系统里测 Fuse/接触器两端高压、BJB 绝缘电压，配低边 shunt 做电流采样。ESS 应用中做冗余电流检测的主角（SDAA369 提及）。

## 关键规格

- 17 个单端高压通道：pack/link/charge 测量精度 0.2%；pack 与电芯 VI 同步 64µs
- **2 路独立电流检测 ADC**（B 版）：±0.15% 增益误差漂移，输入 ±275mV
- 2 个过流比较器（B 版）：±1% 精度、双向阈值可编程、硬件引脚自主快速过流保护
- 集成库伦计数（B 版），SoC 计算
- 15 GPIO（IO/I2C/SPI/ADC/测温）、4 个 MOSFET 开关驱动脚
- SPI HUB：可挂 8 组 SPI 设备；隔离双向菊花链（电容/变压器隔离）；与 MCU 走 SPI/UART

## 应用要点

- 双电流 ADC + 独立 RC 路径 = 冗余电流测量，天然支持 shunt 断线诊断（SDAA369 §3.2 方案）
- 区分 B 版（双电流 ADC + 库伦计数）与非 B 版，选型时注意
- 库内还有 Errata（PG-2.0 v2.1）和应用电路图，设计前必读
