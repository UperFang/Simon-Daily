# BQ79718 知识卡片

> 知识卡片 = 结论与指针；原始文件在 Zotero，本地缓存不入 git。

## 是什么

TI **新一代**车规 BMS AFE，18 串监测。家族覆盖 14S/16S/18S：**BQ79714 / BQ79716 / BQ79718**，
变体 BQ79718V（含 VBMS 增强功能）、BQ79718B；通常与 BQ79800 通信桥搭配组成菊花链。

## 关键规格（对比 616 的提升点）

- ADC：每通道独立 ΣΔ ADC，**支持同步采样**（SoC 估计更准）
- 精度：±1.5mV @25°C（2V–4.5V, BOL）
- DLPF：数字低通 10Hz–899Hz 可配置，含 freeze 功能
- 均衡：300mA @85°C，最多 9 通道，支持 PWM 均衡
- GPIO：12 个
- 汇流排：Kelvin 接法（BB 引脚，电池 7~13 底部之间任意位置），不影响测量精度
- 休眠功耗：TSREF 间歇开关，sleep + OTUT + OVUV 仅 ~93µA（616 同条件要 mA 级）

## 断线诊断（与 616 的本质区别：无阈值寄存器）

- **被动常开**：mission 模式下每个 VC 脚挂恒流沉 I_vc、CB 脚挂 I_cb（CB0 为源），连续转换时自动生效，无需 host 写寄存器
- 断线 → Cvc/Ccb 小电容迅速放电 → ADC 读数异常 → **host 侧合理性检查**（plausibility check）判定，无专用 OW 故障位
- CB 脚另有主动诊断：`DIAG_CBFETOW_GO`（18 个均衡管分 6 组轮询，`FAULT_CB_FETOW 1-3`）
- BB 脚：2×I_vc 电流沉，断线时 Vcell 读数异常升高（Vbusbar = Vcb − Vvc）
- 详细安全机制见 FS Manual：SM_VC_OPN_DET、SM_CB_OPN_DET
