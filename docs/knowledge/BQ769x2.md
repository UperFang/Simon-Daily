# BQ769x2 知识卡片

> 知识卡片 = 结论与指针；原始文件在 Zotero，本地缓存不入 git。

## 是什么

TI **3–16 串高精度电池监测器 + 保护器**家族（BQ76952/76942/76972…，xy 后缀区分版本），面向储能、BBU、LEV 等非车规/工业电池包。有公开版中文 datasheet（ZHCSU48/SLUSFC9）和完整 TRM，是资料最全的入门家族。注意：它是**非菊花链**架构（I2C/SPI/HDQ 直连 MCU），与 BQ79xxx 菊花链族定位不同。

## 关键规格（以 BQ76972 为例）

- 3–16S，±3.0mV 电芯电压精度；85V 引脚耐压
- 2 个独立 ADC：电流电压同步采样；库伦计数输入偏移 <1µV
- 集成高侧 NFET 电荷泵驱动（可选自主恢复）；化学熔丝驱动二级保护
- 保护套件：电压/温度/电流/内部诊断（CUV/COV 触发次序与断线判别应用见 BQ79616 断线分析卡）
- 均衡：自主或主机控制
- 功耗：NORMAL 286µA；SLEEP 24–41µA；DEEPSLEEP 9–10µA；SHUTDOWN 1µA
- 温度：内部传感器 + 最多 9 个外部热敏电阻
- OTP 量产编程；通信 400kHz I2C / SPI / HDQ；双路 LDO；48 引脚 TQFP

## 应用要点

- 无专用断线标志位，断线靠 COV/CUV + VBAT vs ΣVCELL 甄别（SDAA369 有完整方法）
- 软件开发参考《BQ769x2 Software Development Guide》（库内 Sunna 2020）、校准与 OTP 编程指南
- 库内还有中文实战文档：《BQ76952 短路保护 DSG FET 损坏原因分析和优化方法》《高侧 NMOS 堆叠式设计注意事项》——踩坑经验，设计前读
