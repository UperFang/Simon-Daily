# LMG3100 知识卡片（100V GaN FET 集成驱动器）+ 库内 GaN 资料地图

> 知识卡片 = 结论与指针；原始文件在 Zotero，本地缓存不入 git。

## 是什么

TI **100V GaN FET + 集成驱动器**（半桥拆颗即用）：两个 LMG3100 即构成一个半桥，无需外部电平转换器。

## 关键规格

- 两个型号：**LMG3100R017**（126A / 1.7mΩ）、**LMG3100R044**（46A / 4.4mΩ）
- 100V 连续 / 120V 脉冲；集成高侧电平转换 + 自举；自举电压钳位防过驱动
- 开关频率最高 10MHz；高摆率低振铃；3.3V/5V 逻辑兼容
- 无键合线封装（6.5mm×4mm×0.89mm QFN），顶面+底面双散热
- 零反向恢复、极小 Ciss/Coss——GaN 固有优势

## 库内 GaN 资料地图（48V EPS 方向）

- LMG3100R017（lmg3100r017.pdf，ZHCSUG9B，中文公开版）、LMG2100R026（更低电压族）
- **《Schematic and Layout guidelines for paralleling LMG3100》** + **《LMG3100 Paralleling Test Results-Customer》**——并联应用的两份实操文档（设计规范+实测数据），做 48V 大电流 EPS 时重点看
- 《20250122 GaN EPS.docx》《48V GaN EPS Application.pptx》——EPS 应用方案材料

## 应用要点

- 48V EPS / 电机驱动场景：LMG3100 并联扩流是库内资料的重点方向，注意并联均流与布局规范
- 应用面广：降压/升压/LLC、光伏逆变器、通信电源、D 类功放
