# BQ7988x 知识卡片（BQ79888 / BQ79881）

> 知识卡片 = 结论与指针；原始文件在 Zotero，本地缓存不入 git。

## 是什么

TI **Smart EIS 传感家族**两颗兄弟芯片（Product Preview / 较新资料，2024–2026）：

- **BQ79888-Q1**：4–18S 车规电池监测器 + 片上 ASIL-D EIS 引擎，集成高侧 FET 驱动
- **BQ79881-Q1**：**UIR 传感器**（绝缘电阻监测）+ Pack 级 EIS + 高压/电流监测，面向 EV BMS 高压域

## 关键规格

### BQ79888-Q1
- 4–18S，每电芯独立 ADC，<1.6mV 精度，ASIL-D
- 双电流采样路径、超低失调、活跃/休眠态 <5µs 过流检测、内置库伦计数
- EIS 引擎：1% 阻抗精度，器件间同步 <5µs
- 集成高侧 FET 驱动：<1µs 开关、受控软启动免预充电路
- 功耗：关机 <5µA、休眠 <10µA（自主安全监测）；11 GPIO；300mA 被动均衡；IDDQ 监测
- 封装：76 引脚可湿侧翼 QFN（Product Preview，量产前注意文档时效）

### BQ79881-Q1
- 双路快速 pack 电压测量（ASIL-D，<0.4% 精度，0µs VI 同步）
- 18 个单端 ADC 输入（1.8V/2.5V/3.3V 基准可选）
- **4 路电流检测 ADC**（测两路电流）：±275mV 差分，0.1% 精度（50µΩ shunt 下 10mA）
- 快速过流比较器：100µs–1ms 响应，1% 精度，多数表决选项
- Smart EIS 引擎（1% 精度，0.01Hz–3.5kHz，全局激励）
- 菊花链升级版：双路并行 SPI 支持分裂链、2Mbps 单链/环、BCI 闭环 200mA、FDTI <100ms（800V/250 串）
- 12V 开关驱动脚（驱动 NMOS/继电器，绝缘电阻测量的开关矩阵用）

## 应用要点

- 绝缘电阻（IR）监测是 79881 的差异化能力：配 12V 驱动脚做激励开关，Pack 级 IR + EIS + VIC 一颗搞定
- 库内有 BQ79881 EVM 用户指南（SLUUD06）可复现测试
