# BQ79616-Q1 知识卡片

> 知识卡片 = 结论与指针；原始文件在 Zotero，本地缓存不入 git。

## 是什么

TI **老一代**车规 BMS AFE（电池监测模拟前端），16 串电池监测，ASIL-D。
同代家族：BQ79614（14S）、BQ79612（12S），另有 BQ79616H 变体。已被 BQ7971x 家族接替。

## 关键规格

- ADC：2× SAR ADC（主 + 冗余），非每通道独立 ADC
- 精度：-2.2mV/1.5mV @25°C（2V–4.5V, BOL）
- 均衡：240mA @80°C 环温，最多 8 通道
- GPIO：8 个
- 汇流排（BB）：走专用 BBP/BBN 引脚，或占用 VC 通道

## 断线诊断（本芯片特色：阈值可调）

- **主动式诊断**：host 发起，`DIAG_COMP_CTRL3[OW_SNK1:0]` 开电流沉（VC/CB/BBP-N 三组），等 dV/dt 放电后比较
- **阈值可调**：`DIAG_COMP_CTRL2[OW_THR3:0]`，500mV~5V，300mV 步进（判据 VCELL < OW_THR）
- 结果寄存器：`FAULT_COMP_VCOW1/2`、`FAULT_COMP_CBOW1/2`；完成标志 `ADC_STAT2[DRDY_VCOW/CBOW]`
- 渐变断线"先报断线、后报 OV/UV"的方法：见 [BQ79616_断线诊断分析](BQ79616_断线诊断分析.md)
