# BQ79826 知识卡片

> 知识卡片 = 结论与指针；原始文件在 Zotero，本地缓存不入 git。

## 是什么

TI 新一代**高串数车规 BMS AFE**：26S/24S 电池监测 + **Smart EIS Engine**（片上电化学阻抗谱引擎）。BQ7971x 之后的下一代平台，EV + ESS 双应用。注意：Z = 带温压传感变体；2025-09 版 SLUSF38。

## 关键规格

- **26 通道**：电芯 0–5.5V；汇流排 -2V~2V（除首通道外每通道都支持 busbar）；Abs Max 143V；可堆叠 128 颗
- 精度：<1.7mV（-40~125°C）；**每通道独立 ADC + 同步冗余测量**
- 均衡：集成 FET 被动均衡 300mA@85°C，奇偶分批 + 可编程 PWM
- **Smart EIS**：阻抗精度 1%（1A 激励、200µΩ），0.01Hz–3.5kHz，器件间 I/V 同步 <5µs，支持全局/局部激励
- 传感：20 GPIO（NTC/PTC、电压、中断）、压力阈值/峰值检测、SPI/I2C
- 诊断保护：<20µA 监测模式；OVUV/OTUT；2× 结温；开线检测；反向唤醒；冗余路径
- 菊花链：2Mbps（双 SPI 4Mbps）、器件间同步 ±5µs、BCI 闭环 200mA/开环 300mA、FDTI <100ms（800V/250 串）、支持 stack/ring/multidrop/split-ring
- 电源：集成 DC-DC；关机 <10µA；带监测休眠 20µA；激活 <5mA
- 封装：100 引脚 QFP，4mm 间距

## 应用要点

- EIS 是差异化卖点：老化/SoC/热失控等电芯内部状态监测（与 BQ79888/79881 同族 EIS 能力）
- 与 BQ79800 通信桥（双 SPI）搭配组网，参考《BQ798xx_Communications_Reference_Guide》
- 与 BQ79718 对比：串数 18→26、每通道独立 ADC、EIS 加成（详见迁移指南条目）
