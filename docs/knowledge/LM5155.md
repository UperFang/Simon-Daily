# LM5155 知识卡片（宽压隔离反激控制器）+ 库内应用笔记地图

> 知识卡片 = 结论与指针；原始文件在 Zotero，本地缓存不入 git。

## 是什么

TI 宽输入电压范围**电流型控制器**，库内用法聚焦：**隔离反激（Flyback）偏置电源设计**——为 BMS/数字电源提供辅助电源。⚠️ LM5155 本体的 datasheet 未入库，规格以 ti.com 最新版为准。

## 应用要点

- 偏置电源设计三件套：拓扑选型（PSR/SSR）→ 软启动 → 不符合项案例复盘，库内资料已成体系
- BMS 场景下偏置电源常从 pack 取电，注意宽压与隔离等级要求
