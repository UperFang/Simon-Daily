```

## Zotero 读取（本地自由使用）

```
python3 scripts/zotero_lib.py              # 最近 20 条
python3 scripts/zotero_lib.py 50           # 最近 50 条
python3 scripts/zotero_lib.py -s 关键词     # 搜索（附原文路径）
python3 scripts/zotero_lib.py --tree       # 分类树（结构以此为准）
python3 scripts/zotero_lib.py --collections# 平铺分类列表
python3 scripts/zotero_lib.py -c "分类名"   # 某分类下条目（附路径）
python3 scripts/zotero_lib.py --updates    # 上次检查以来的新增（刷新时间戳）
```
- 原理：文件快照读 `~/Zotero/zotero.sqlite`，Zotero 运行中安全
- 原文 PDF 直接用 Read 工具读（已装 poppler）

## Zotero 写入（导入资料）

```
python3 scripts/zotero_add.py <文件> --collection "FAE&Work/2- BMS/1- TI - BQ" \
    --kind Datasheet --title "BQ79616-Q1（SLUSD77）" [--tags BMS,TI] [--url ...] [--date ...]
```
- `--collection` 支持父/子路径；绝不自动创建分类
- `--kind` 自动加 `[类型]` 前缀（已有 `[` 则不重复）；类型词表见 docs/Zotero目录结构.md
- 前提：Zotero 运行中且本地 API 已开启；API key 在钥匙串（`zotero-api-key`），失效时重新 `/api/local/authorize` 授权后存回钥匙串

## 环境自检 + 缓存清理（启动例程自动跑）

python3 scripts/self_check.py             # 16 项自检：脚本/密钥/路径/卡片清单/红线/结构漂移/待决建议

```
