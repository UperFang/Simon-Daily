# 搜索策略（联网检索详细规则）

> 铁律级别的「分级检索流程」在 CLAUDE.md；本文件是联网时的执行细节。

## 分级检索流程（回顾）

1. 先查本地：Zotero（`zotero_lib.py -s`）+ `docs/knowledge/` 知识卡片
2. 不完备 → **先询问**「要联网搜吗？」→ 同意后联网
3. 联网仍不完备 → 如实说明缺口（缺什么、可能原因），由 Wonder 决定下一步
- 豁免：通用常识、Wonder 明确要求联网的问题可直接联网

## 信源优先级（用 `site:` 语法定向）

1. `site:ti.com` —— 产品页、Datasheet、Application Note
2. `site:e2e.ti.com` —— TI E2E 论坛（应用疑难杂症常有人讨论过）
3. 竞品原厂：`site:infineon.com`、`site:nxp.com`、`site:analog.com`
4. 其他原厂按需：st.com、renesas.com、onsemi.com、microchip.com
5. 分销商兜底：mouser.com、digikey.com、szlcsc.com（立创）

## Datasheet 惯例

- PDF **不要网页抓取**：下载到 `data/datasheets/`（gitignore）后用 Read 读文件
- 下载后有价值就导入 Zotero（`zotero_add.py`，归档纪律见 docs/Zotero目录结构.md）
- 本地缓存 3 天保鲜期，`cleanup_cache.py` 自动清（Zotero 有正本才删）

## 工具选择

- **WebSearch**：首选搜索；支持 `site:` 定向
- **WebFetch**：抓指定网页转文字；**失败（超时/反爬）时自动换 webReader 重试**
- **webReader**（MCP）：备胎阅读器，E2E、eet-china 等站点实测可用
- 登录墙内容抓不了 → 请 Wonder 存网页到 `data/`，我来分析
